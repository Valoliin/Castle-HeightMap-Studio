# Textures et calques

Chaque image chargée devient un **calque** indépendant.

## Manipulation

Une texture sélectionnée possède huit poignées :

- les quatre coins redimensionnent X et Y ;
- gauche/droite modifient uniquement la largeur ;
- haut/bas modifient uniquement la hauteur ;
- un glisser au centre déplace l'image.

## Calques

Le panneau des calques permet de :

- sélectionner ;
- renommer ;
- afficher ou masquer ;
- verrouiller ;
- monter ou descendre dans la pile ;
- dupliquer ;
- supprimer.

## Position précise

La position et les dimensions peuvent aussi être saisies en **millimètres**.

Cela permet par exemple de réserver exactement 15 mm sans relief autour d'un capteur.
