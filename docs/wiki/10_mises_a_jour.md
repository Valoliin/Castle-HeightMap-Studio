# Mises à jour

Le menu :

```text
Aide → Rechercher les mises à jour
```

consulte la dernière **GitHub Release**.

Le logiciel recherche automatiquement :

- un `.exe` sous Windows ;
- une `.AppImage` sous Linux ;
- sinon une archive ZIP.

## Sécurité

Castle HeightMap Studio ne remplace pas silencieusement le programme en cours d'utilisation.

La nouvelle version est téléchargée puis l'utilisateur peut fermer l'ancienne version et lancer la nouvelle.
