# Masques

Les masques forcent localement le relief à **zéro**.

Ils sont utiles pour garder une zone parfaitement plane.

## Outils

### Pinceau
Pour nettoyer librement une zone irrégulière.

### Rectangle
Pour une trappe, une plaque, une fixation ou une zone d'assemblage.

### Cercle / ellipse
Pour un capteur, un trou circulaire ou un élément décoratif.

## Exemples

Un masque peut servir à réserver :

- une zone de collage ;
- un logement de capteur ;
- une fixation mécanique ;
- un blason séparé ;
- une surface destinée à un autre corps FreeCAD.
