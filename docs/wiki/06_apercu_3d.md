# Aperçu 3D

L'aperçu 3D permet de vérifier le relief avant l'export STEP.

Il est particulièrement utile pour détecter :

- un relief trop élevé ;
- des joints trop profonds ;
- une texture trop étirée ;
- une zone qui aurait dû rester lisse ;
- un raccord visible.

L'aperçu est volontairement plus léger que la géométrie STEP finale afin de rester interactif.
