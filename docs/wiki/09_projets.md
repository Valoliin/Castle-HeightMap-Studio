# Projets

Les projets utilisent l'extension :

```text
.castlehm
```

Ils conservent :

- dimensions du mur ;
- textures ;
- positions et tailles ;
- rotations ;
- calques ;
- masques ;
- paramètres de traitement ;
- réglages STEP.

## Raccourcis

- `Ctrl+N` : nouveau projet
- `Ctrl+O` : ouvrir
- `Ctrl+S` : enregistrer
- `Ctrl+Shift+S` : enregistrer sous
- `Ctrl+Z` : annuler
- `Ctrl+Y` : rétablir
